trj.(THEREALJOURNEY, 이하 "앱")는 여행 일정을 만들고 기록하는 웹앱입니다. 앱은 회원 가입이 없고, 여행 내용을 운영자 서버에 저장하지 않습니다.

1. 저장하는 정보와 위치

  • 이 기기: 여행 일정, 항공편, 예산, 준비물, 기록 글과 사진은 사용하는 브라우저 안(localStorage, IndexedDB)에 저장됩니다.
  • 사용자의 Google Drive: Drive 저장을 켠 경우에만, 여행 내용과 기록 사진을 사용자 본인의 Google Drive에 있는 TRJ 폴더에 파일로 저장합니다. 함께 편집하는 여행의 사진은 동행이 볼 수 있도록 '링크가 있는 사람은 보기 가능'으로 설정되며, 링크 주소는 그 여행 파일에만 기록됩니다.
  • 운영자는 위 정보를 받거나 볼 수 없습니다. 단, 사용자가 '보기 링크'를 만든 여행은 아래 4항처럼 앱 서버에 저장됩니다.

2. Google 계정 데이터 사용

  • 앱은 drive.file 권한만 요청합니다. 이 권한으로는 앱이 만든 파일과 사용자가 직접 선택한 파일에만 접근할 수 있고, Drive의 다른 파일은 볼 수 없습니다.
  • 함께 편집을 쓰면, 사용자가 입력한 동행의 Google 계정에 Drive 편집 권한을 줍니다 (초대장은 사용자가 직접 보냅니다). 편집자 목록(이름·이메일)은 공유 상태를 보여 주는 데에만 사용합니다.
  • Google 로그인 정보(액세스 토큰)는 브라우저 메모리에만 두고 저장하거나 전송하지 않습니다.
  • 앱이 Google API로부터 받은 정보의 사용과 이전은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 받은 정보는 광고에 사용하거나 판매하지 않으며, AI 모델 학습에 사용하지 않습니다.

3. 외부 서비스로 보내는 정보

  • AI 일정 추천 (Google Gemini): 추천을 요청하면 목적지, 여행 날짜, 여행 속도, 고른 관심사, 이미 일정에 있는 장소 이름을 앱의 서버 함수를 거쳐 Google Gemini API로 보냅니다. 이름·이메일 같은 개인 정보는 보내지 않으며, 서버 함수는 요청 내용을 저장하지 않습니다.
  • 내용 옮겨 보기 (Cloudflare Workers AI, Google Gemini): 함께 쓰는 여행에 다른 언어로 적힌 장소·숙소 이름, 메모, 지출 이름, 준비물을 한국어·영어로 보여 주기 위해 그 글만 앱의 서버 함수로 보내 Cloudflare Workers AI 번역 모델로 옮기고, 그것이 안 되면 Gemini API로 옮깁니다. 크롬처럼 기기 안 번역을 지원하는 브라우저에서는 기기 안에서 먼저 옮깁니다. 함께 쓰는 여행이면 번역 결과를 여행 파일에 함께 저장해 동행에게 전달합니다. 여행 관리에서 끌 수 있습니다.
  • 장소 이름 바꾸기 (Google Gemini): 검색 결과에 한국어(영어) 이름이 없는 곳은 그 장소 이름만 같은 서버 함수를 거쳐 Gemini API로 보내 표기를 받습니다.
  • 지도 (OpenFreeMap): 지도를 그리기 위해 보고 있는 지역의 지도 조각을 받아 옵니다.
  • 장소 검색 (OpenStreetMap Nominatim): 검색창에 입력한 장소 이름을 보냅니다. '사진으로 추가'에서는 사진에서 읽은 가게 이름, 또는 사진에 위치 정보가 있으면 그 좌표를 보내 장소를 찾습니다.
  • 사진으로 추가 (기기 안에서 처리): 사진과 예약 확인서 PDF의 글자는 이 기기 안에서 인식하며 파일 자체는 어디에도 보내지 않습니다. 글자 인식 엔진과 언어 데이터는 처음 한 번 jsDelivr(CDN)에서 받아 브라우저에 저장합니다.
  • 호스팅 (Cloudflare): 앱 파일을 전달하는 과정에서 Cloudflare가 접속 기록(IP 주소 등)을 처리할 수 있습니다.

4. 공유

'고칠 수 있는 사본' 링크는 여행 내용(사진 제외)을 링크 주소 안에 담습니다. '보기 링크'를 만들면 날짜별 장소·항공편·숙소·지출·준비물과 동행 이름을 앱 서버(Cloudflare KV)에 저장하고 짧은 링크를 만듭니다. 동행 이메일·예약번호·좌석·기록(글과 사진)은 담지 않습니다. 여행을 고치면 저장된 내용도 바뀌고, 보기 링크를 끄면 지워집니다. 400일 동안 고치지 않으면 자동으로 지워집니다. 어느 링크든 받은 사람은 그 내용을 볼 수 있으니 공유할 상대를 확인하세요.

5. 삭제

  • 기기의 정보: 앱에서 여행을 삭제하거나 브라우저의 사이트 데이터를 지우면 삭제됩니다.
  • Drive의 정보: Google Drive의 TRJ 폴더에서 파일을 삭제하면 됩니다. 앱의 Drive 접근 권한은 Google 계정 → 서드 파티 연결에서 언제든 해제할 수 있습니다.

Privacy Policy

Effective November 18, 2026

trj. (THEREALJOURNEY, "the app") is a web app for planning and recording trips. There is no sign-up, and the app does not store your trips on its operator's servers.

1. What is stored, and where

  • This device: itineraries, flights, budgets, packing lists, journal text and photos are stored in your browser (localStorage, IndexedDB).
  • Your Google Drive: only if you turn on Drive saving, trip contents and journal photos are saved as files in a TRJ folder in your own Google Drive. Photos in a co-edited trip are set to "anyone with the link can view" so companions can see them; the links are recorded only in that trip file.
  • The operator does not receive or see this information, except for trips you create a "view link" for, which are stored on the app server as described in section 4.

2. Use of Google user data

  • The app requests only the drive.file scope. It can access only files the app created or files you choose, and cannot see the rest of your Drive.
  • When you edit together, the companion Google accounts you enter get editing access in Drive (you send the invite yourself). The list of editors (names and emails) is used only to show who the trip is shared with.
  • Your Google access token stays in browser memory and is never stored or transmitted elsewhere.
  • The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This information is not used for advertising, not sold, and not used to train AI models.

3. Information sent to other services

  • AI suggestions (Google Gemini): when you ask for suggestions, the destination, dates, pace, selected interests and names of places already in the plan are sent through the app's server function to the Google Gemini API. No names or email addresses are sent, and the server function does not store requests.
  • Translating shared content (Cloudflare Workers AI, Google Gemini): to show place and stay names, notes, expense names and checklist items in Korean or English, only that text is sent to the app's server function and translated with a Cloudflare Workers AI translation model, or the Gemini API if that fails. Browsers with on-device translation (such as Chrome) translate on the device first. For shared trips the translations are saved in the trip file so companions get them. You can turn this off in trip settings.
  • Place name translation (Google Gemini): for search results without a Korean (or English) name, only those place names are sent through the same server function to the Gemini API.
  • Maps (OpenFreeMap): map tiles for the area you are viewing are downloaded.
  • Place search (OpenStreetMap Nominatim): the place name you type is sent. In "Add from photo", the shop name read from the photo, or the photo's coordinates if it has location data, is sent to find the place.
  • Add from photo (on device): text in photos and booking PDFs is recognized on this device and the files themselves are never sent anywhere. The recognition engine and language data are downloaded once from jsDelivr (a CDN) and kept in the browser.
  • Hosting (Cloudflare): Cloudflare may process connection logs (such as IP addresses) while delivering the app.

4. Sharing

An "editable copy" link carries the trip contents (without photos) inside the link itself. A "view link" stores the daily places, flights, stays, expenses, checklist and companion names on the app server (Cloudflare KV) behind a short link. Companion emails, booking numbers, seats and the journal (text and photos) are not included. Edits to the trip update it, turning the view link off deletes it, and it is deleted automatically after 400 days without edits. Anyone with any of these links can see their contents, so check who you send them to.

5. Deletion

  • On this device: delete the trip in the app, or clear the site's data in your browser.
  • In Drive: delete the files in your TRJ folder. You can revoke the app's Drive access at any time under Google Account → Third-party connections.
